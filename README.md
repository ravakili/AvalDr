# اول دکتر — Dr. Saina

یک وب‌اپ کامل **مشاوره پزشکی آنلاین** با رابط کاربری **فارسی (RTL)**، فونت **Vazirmatn** و طراحی **گلس‌مورفیسم (شیشه‌ای) مینیمال**. سه پنل مجزا برای **بیمار**، **پزشک** و **مدیر**.

A fully functional, RTL, Persian online medical consulting web app built with **React + TypeScript + Vite + Tailwind CSS + Zustand + React Router v6**. Glassmorphism, minimal, modern aesthetic.

---

## ✨ ویژگی‌ها / Features

- 🎨 **طراحی شیشه‌ای (Glassmorphism):** `backdrop-blur-lg`، `bg-white/10`، `border border-white/20`، گرادیان نرم آبی-فیروزه‌ای
- 🇮🇷 **کاملاً RTL و فارسی** با فونت Vazirmatn و اعداد فارسی
- 🔐 **احراز هویت شبیه‌سازی‌شده** با انتخاب نقش (بیمار / پزشک / مدیر) و ذخیره در `localStorage`
- 🛡️ **مسیرهای محافظت‌شده** و هدایت خودکار بر اساس نقش (`/user`, `/doctor`, `/admin`)
- 🧩 **کامپوننت‌های قابل‌استفاده مجدد:** `GlassCard`, `PrimaryButton`, `InputField`, `Badge`, `Modal`, `Avatar`, `StatCard`, `Sidebar`
- 💬 **چت مشاوره تعاملی** با ارسال پیام، پاسخ خودکار بیمار، صدور نسخه و پایان جلسه
- 📊 **داشبورد مدیریت کامل** شامل جدول پزشکان با عملیات تأیید/تعلیق/حذف

## 🚀 اجرا / Getting Started

```bash
# 1. نصب وابستگی‌ها
npm install

# 2. اجرای محیط توسعه (پورت ۵۱۷۳)
npm run dev

# 3. ساخت نسخه تولید
npm run build

# 4. پیش‌نمایش نسخه تولید
npm run preview
```

سپس مرورگر را روی `http://localhost:5173` باز کنید.

### ورود / Login

در صفحه ورود، **نقش** را انتخاب کنید (بیمار، پزشک یا مدیر) و دکمه **«ورود»** را بزنید. هیچ پسورد واقعی لازم نیست — داده‌ها موک هستند. هر نقش به پنل مخصوص خود هدایت می‌شود.

## 📝 یادداشت / Notes

- تمام داده‌ها **موک** و در `src/data/mockData.ts` قرار دارند — بدون بک‌اند واقعی.
- حساب کاربری فعلی در `localStorage` ذخیره می‌شود (کلید `AvalDr-auth`). برای ورود دوباره از نقش دیگر، دکمه خروج (آیکون ← در پایین سایدبار) را بزنید.
- چت مشاوره با پاسخ خودکار بیمار، پیام‌های نسخه‌ای و مودال صدور نسخه چنددارویی کامل شده است.
- مسیرها کاملاً محافظت‌شده‌اند: کاربر نمی‌تواند به پنل نقش دیگر دسترسی پیدا کند.

ساخته‌شده با ❤️ برای نمایش طراحی رابط کاربری پزشکی مدرن.
