## ✨ نگاه کلی

**اول دکتر** یک اپلیکیشن تحت وب **مشاوره پزشکی آنلاین** است که با طراحی **Glassmorphism** و پشتیبانی کامل از **زبان فارسی و راست‌چین (RTL)** ساخته شده. سه پنل مجزا با قابلیت‌های کامل:

| پنل | کاربران | قابلیت‌های کلیدی |
|-----|---------|------------------|
| 🧑‍💻 **بیمار** | کاربران عادی | 🔍 جستجوی پزشک، 📅 رزرو نوبت با تقویم و درگاه پرداخت شبیه‌سازی‌شده، 💬 ورود به مشاوره، 📄 آپلود گزارش پزشکی، 🧾 مشاهده نسخه‌ها |
| 🩺 **پزشک** | پزشکان متخصص | 📊 نمای کلی ویزیت‌ها، 💬 چت تعاملی با صدور نسخه و ویدئوکال، 👥 مدیریت بیماران، ⚙️ پروفایل حرفه‌ای با ساعات کاری و تعرفه |
| 🛡️ **مدیر** | مدیران سامانه | 👨‍⚕️ مدیریت و تأیید پزشکان، 👤 مدیریت کاربران، 📋 تعاریف سیستم (تخصص‌ها، تشخیص‌ها، داروها، ...)، 📈 لاگ نوبت‌ها، 💰 برداشت‌ها |

---

## 🎨 طراحی

- **Glassmorphism** — کارت‌های شیشه‌ای با `backdrop-blur` و `bg-white/50`
- **رنگ پویا** — پشتیبانی از ۶ تم رنگی (فیروزه‌ای default، نیلی، صورتی، قرمز، سبز، زمردی) با تغییر آنی از طریق `data-accent`
- **حالت تاریک** — `html.dark` با تمام المان‌های شیشه‌ای سازگار
- **انیمیشن Lottie** — آیکون قلب HealthTap در سایدبار با رنگ‌های هماهنگ با تم
- **فونت Vazirmatn** — فونت وزیرمتن برای خوانایی عالی فارسی
- **کاملاً RTL** — با پلاگین `tailwindcss-rtl`

## 🚀 اجرای سریع

```bash
# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه
npm run dev

# ساخت نسخه نهایی
npm run build
```

سپس `http://localhost:5173` را باز کنید. در صفحه ورود، نقش دلخواه را انتخاب کرده و وارد شوید — بدون نیاز به رمز واقعی، تمام داده‌ها موک هستند.

## 🔧 تکنولوژی‌ها

| لایه | تکنولوژی | کاربرد |
|------|----------|--------|

| **Charts** | Recharts | نمودارهای آماری پنل مدیریت |

| **Icons** | Lucide React + React Icons | کتابخانه گسترده آیکون |
| **Avatars** | DiceBear API | آواتارهای تصادفی برای پزشکان و بیماران |

## 👥 راهنمای نقش‌ها

### 🧑‍💻 پنل بیمار (`/user`)
- **خانه**: کارت‌های آماری، نوبت بعدی با شمارش معکوس، لیست نوبت‌ها، نسخه‌های اخیر، آپلود گزارش پزشکی، نکات سلامتی
- **جستجوی پزشک**: فیلتر بر اساس تخصص و شهر، مشاهده پروفایل کامل
- **نوبت‌های من**: فیلتر بر اساس وضعیت و تاریخ، تغییر زمان، ورود به مشاوره
- **پروفایل**: اطلاعات شخصی، پرونده پزشکی (تشخیص‌ها، حساسیت‌ها، داروها)، گزارش‌های پزشکی، تنظیمات اعلان

### 🩺 پنل پزشک (`/doctor`)
- **نمای کلی**: آمار ویزیت‌ها، درخواست‌های جدید
- **نوبت‌ها**: لیست بیماران با امکان مشاهده پرونده و صدور نسخه
- **بیماران**: مدیریت بیماران، ارسال پیام، نوبت‌های پیگیری
- **پروفایل**: اطلاعات حرفه‌ای، ساعات کاری (بدون تداخل)، تعرفه مشاوره، اطلاعات بانکی
- **مشاوره**: چت تعاملی با ویدئوکال، صدور نسخه دارویی، آپلود فایل

### 🛡️ پنل مدیر (`/admin`)
- **نمای کلی**: آمار سامانه، درخواست‌های تأیید پزشکان
- **پزشکان**: تأیید، تعلیق، افزودن پزشک جدید با آپلود مدارک
- **کاربران**: مشاهده پروفایل، سوابق پزشکی، اسناد، تعلیق کاربران
- **تعاریف**: مدیریت تخصص‌ها، تشخیص‌ها، آلرژی‌ها، داروها، شهرها، نکات سلامتی
- **لاگ نوبت‌ها**: سوابق کامل فعالیت‌ها
- **برداشت‌ها**: مدیریت درخواست‌های تسویه پزشکان
- **تنظیمات**: پیکربندی پلتفرم و تنظیمات تم

## 🧩 ویژگی‌های خاص

- **چت تعاملی**: پیام‌های دوطرفه با پاسخ خودکار بیمار، صدور نسخه چنددارویی، ویدئوکال با کنترل صدا/دوربین/اشتراک‌صفحه
- **درگاه پرداخت شبیه‌سازی‌شده**: فرم کارت بانکی با تایمر ۵ دقیقه‌ای
- **تغییر زمان نوبت**: انتخاب روز و ساعت از هفت روز آینده
- **آپلود گزارش پزشکی**: پشتیبانی از PDF، JPG، PNG، DOC با دکمه ذخیره
- **نوبت پیگیری**: رزرو نوبت جدید بر اساس ساعات کاری پزشک
- **تداخل سنجی ساعات کاری**: جلوگیری از ثبت ساعات کاری همپوشانی در پروفایل پزشک
- **انیمیشن Lottie پویا**: Heart HealthTap Spinner با رنگ‌های هماهنگ با تم و پشتیبانی از دارک مود

## 📝 نکات

- تمام داده‌ها **موک** هستند و در `src/data/mockData.ts` قرار دارند — بدون نیاز به بک‌اند
- احراز هویت در `localStorage` با کلید `AvalDr-auth` ذخیره می‌شود
- برای تست نقش‌های مختلف، از دکمه خروج در سایدبار استفاده کنید
- تم رنگی از طریق `SystemSettings` در پنل ادمین یا ست کردن دستی `data-accent` روی `<html>` قابل تغییر است
- دارک مود با افزودن کلاس `.dark` به `<html>` فعال می‌شود
